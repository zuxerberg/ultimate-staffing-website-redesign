# Ultimate Staffing Boca Raton Redesign

Editable standalone React/Vite source exported from the ChatGPT Sites version.

## Local Development

Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

Build a production copy:

```bash
npm run build
```

## Project Structure

- `src/main.jsx` contains the React components and page content.
- `src/styles.css` contains the full responsive stylesheet.
- `public/assets/` contains the supplied logo and image assets.
- `index.html` contains metadata, font references, and the Vite root element.

This export does not require ChatGPT Sites to run.
